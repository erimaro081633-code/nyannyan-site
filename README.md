# nyannyan-site
# 猫カフェ・ペットショップ「にゃんにゃん」Webサイト制作ログ

本プロジェクトは、AI支援ツール（Claude Code）を活用して作成し、要件定義・表示確認・レイアウト崩れの修正を行った提出用Webページです。

---

## 1. 初期投入プロンプト（指示文）

あなたはペットショップの店員です。
HTML/CSSを使って案内ホームページを作りたい。

【条件】
店名：にゃんにゃん
場所：板橋
営業時間：10:00〜18:00
おすすめのペット：猫、大型犬（取り扱いは子犬）

・店名や場所は文字大きく。
・おすすめのペット犬、猫はフリー素材でいいから2枚ずつ写真を付けて。
・スマホでも見やすく。

---

## 2. 追加要件・要素追加指示プロンプト

・見出し、段落、画像に加えて、店舗情報のリストや表、ナビゲーションなどを入れ、3種類以上のHTML要素が使われていることを確認してください。
・「作成後にブラウザで表示し、画像・文字サイズ・レイアウト崩れを確認して修正してください」

---

## 3. 要件チェック結果と主要な修正内容

ブラウザおよびコードの確認を実施し、以下の不備を修正・最適化しました。

| 要件               | 修正前の状態                                | 修正内容                                                                                     |
| ------------------ | ------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **見出し**         | `h2`・`h3`はあるが最高位の見出しがない      | ヒーロー部分に `<h1>` を追加し、`h1 → h2 → h3` の正しい階層構造に整理                        |
| **段落**           | `<p>` を各セクションで使用                  | 問題なし（既存の構成を維持）                                                                 |
| **画像**           | 画像URLにスペースが含まれ読み込み失敗の懸念 | URLをエンコードし、読み込み失敗時用の `onerror`（プレースホルダー画像切り替え）を追加        |
| **リスト / 表**    | 表（`<table>`）のみで箇条書きリストがない   | 店舗情報セクションに「取り扱い内容」の箇条書きリスト（`<ul><li>`）を追加                     |
| **ナビゲーション** | モバイル表示（760px以下）で完全非表示になる | スマホ幅でもナビ機能を損なわないよう、フッター内に補完用のナビリンクを自動表示する仕様へ調整 |

## 4. Claude Code による最終実装・レスポンシブ検証

### デザインパレット・書体

- 配色：フォレストグリーン（Forest Green: `#3F5F45`）× アンバー/コーラル（`#C2604A`）
- 書体：Fraunces / Work Sans

### 実装したHTML要素（6種類以上）

- 最高位見出し（`<h1>`）および中・小見出し（`<h2>`, `<h3>`）
- 段落（`<p>`）
- 画像（`<img>`：`onerror` フォールバック対応）
- 箇条書きリスト（`<ul>` + `<li>`）
- 表（`<table>`：営業時間）
- 構造化ナビゲーション（`<nav>` + `<a>`）

### ブラウザ表示確認・レイアウト崩れの修正（デスクトップ／モバイル検証）

1. **フォントサイズ調整 (`clamp`)**
   - 画面幅に応じて文字サイズが自動スケーリングする `clamp()` を導入し、320px程度の極端に狭いスマホ画面でも `h1`（店名）が不格好に折返されないよう調整。
2. **グリッドレイアウトの1カラム化**
   - 760px以下でカード配置・店舗情報が1カラム（縦積み）へ自然に切り替わるようレスポンシブ処理を実施。
3. **ナビゲーションのアクセシビリティ確保**
   - モバイル幅時にヘッダーナビを隠す代わりに、フッター領域へアンカーナビを出力し、モバイルユーザーの回遊性を確保。
